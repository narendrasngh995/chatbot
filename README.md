# Simple AI Chatbot

A basic chatbot built with HTML, CSS, and JavaScript.

## Features

- Clean and modern UI
- Responsive design
- Pattern-based responses
- Typing indicator animation
- Supports various conversation topics

## How to Use

1. Open `index.html` in your web browser
2. Type your message in the input field
3. Press Enter or click Send

## Local Testing

Since this is in your XAMPP directory, you can access it at:
`http://localhost/chatbot/`

## Topics the Chatbot Understands

- Greetings (hi, hello, hey)
- Goodbyes (bye, goodbye)
- Thanks
- Help requests
- Time and date queries
- Jokes
- And more!

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
